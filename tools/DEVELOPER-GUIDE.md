# دليل المطوّر: نقل منصة صنع في مصر إلى الإنتاج

**المنصة:** منصة صنع في مصر · Made in Egypt Gate (`madeinegyptgate.com`)
**المشغّل:** الجمعية المصرية للتنمية الصناعية.
**نوع الحزمة:** موقع ثابت (HTML/CSS/JS بدون إطار عمل) جاهز للرفع على أي استضافة، مع ملفات مصدر لإعادة توليد الصفحات.
**هذه المنصة مستقلة تماماً عن منصتي السعودية والإمارات:** لا تشارك قاعدة بيانات ولا لوحة إدارة.

## 1) محتويات الحزمة

| المجلد / الملف | المحتوى |

| `source/tools/` | سكربتات توليد البيانات من المنصة القديمة والبحث (`gen_old_uae.py`, `gen_real_uae.py`) |

## 2) تشغيل سريع (اختبار محلي)

```bash
cd public && python3 -m http.server 8080
```
ثم افتح `http://localhost:8080`. للنسخة الإنجليزية: `http://localhost:8080/home.html?lang=en`.

### إعادة توليد الصفحات بعد التعديل
```bash
cd source && python3 site.py
```
- الناتج في `source/site/`. يمكن تغيير مجلد الإخراج بالمتغير `MIG_OUT`.
- كل صفحة لها ملف مصدر: `pages.part.py` (الدليل، المركز الإعلامي، اتصل بنا…)، `home2.part.html` (الرئيسية)، `market.part.html` (السوق)، `company.part.py` (ملف المصنع)، `sellers.part.py` (الموردون ومنافذ البيع)، `oldlists.part.py` (المناقصات وطلبات الأسعار)، `legal.part.py` (المركز القانوني والمراجع)، `dash.part.html` (لوحة المصنع)، `seo.part.py` (السيو لكل صفحة).

## 4) خطوات يوم النقل

1. **نسخة احتياطية كاملة من موقع WordPress الحالي** (قاعدة البيانات + `wp-content/uploads`).
2. **Staging أولاً:** ارفع `public/` على نطاق فرعي واختبر قبل تحويل الدومين.
3. **الروابط القديمة:** حافظ على ترتيب جوجل بتحويلات 301:
   ```nginx
   location ^~ /factories/        { return 301 /factories.html; }
   location ^~ /industrial_products/ { return 301 /market.html; }
   location ^~ /tender-item/      { return 301 /tenders.html; }
   location ^~ /rfq/              { return 301 /rfqs.html; }
   ```
   الأفضل: صفحة لكل مصنع على الخادم (`/factories/{slug}/`) بنفس بيانات `company.html`؛ الرابط القديم لكل مصنع موجود في الحقل 7 من `data/oldfac.js`.
4. **SEO:** ارفع `sitemap.xml` و`robots.txt` للجذر وأرسل الـ sitemap إلى Google Search Console وBing.
5. **HTTPS وDNS** ثم متابعة أخطاء 404 لأسبوعين.

## 5) ما يحتاج بناء خادم (Backend)

## 8) الأمان والأداء
- قبل الإطلاق: نقل تسجيل الدخول للخادم، وإضافة رؤوس الأمان (CSP, HSTS, X-Frame-Options).
- ضغط الصور (WebP) وتفعيل التخزين المؤقت للملفات الثابتة؛ الملف الأكبر `data/i18n-en.js` يُحمّل فقط في النسخة الإنجليزية.

## 9) قائمة الفحص بعد الرفع
- [ ] كل الصفحات تفتح بدون أخطاء في الكونسول (عربي وإنجليزي).
- [ ] كل شعار في الرئيسية والدليل يفتح `company.html#…` الصحيح، وزر «ملف مصنع» في السوق يفتح ملف المصنع.
- [ ] تسجيل الدخول للوحة المصنع يعمل من الخادم، وزر «تسجيل الخروج» ينهي الجلسة.
- [ ] الدفع الإلكتروني ينتج فاتورة إلكترونية بضريبة 14%.
- [ ] `sitemap.xml` مقبول في Search Console، والتحويلات 301 للروابط القديمة تعمل.
- [ ] بانرات الشريك الاستراتيجي (المقاولون العرب، Soul Water، السويدي إليكتريك) والشركاء الأساسيين (الملكة، تراست، لاكتو مصر، الهلال والنجمة الفضية) تظهر وتفتح وجهاتها. تُعدَّل من `STRAT` و`PARTNER` في `site.py`.
- [ ] كل ملفات `data/*.js` تُطلب برقم إصدار `?v=` (يتولّد تلقائياً من محتوى الملف عند البناء) فلا يحتاج الزائر لمسح الكاش بعد أي تحديث.

## 10) ملاحظة أمنية عن الموقع الحالي
موقع WordPress الحالي فيه حوالي 130 مقالاً غريباً في أقسام Bypass وLicenses وResettools وUnpackers وHD وTS، وهذا يدل غالباً على اختراق ونشر محتوى سبام. قبل النقل: افحص الموقع والخادم، وغيّر كل كلمات المرور ومفاتيح الإضافات، واحذف هذه المقالات، ولا تنقل أي شيء منها.
