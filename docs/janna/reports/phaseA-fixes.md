### سطور `site.py` المطلوبة من المدمج
1. في `page()`: `+ head + '<script src="data/plan.js"></script>` تبقى `+ head + '<script src="data/plan.js"></script><script src="data/mig-api.js"></script>`
2. بعد سطر `meeting.part.py` (سطر 38):
   `exec(open(B + 'inbox.part.py', encoding='utf-8').read())  # inbox.html: admin requests monitor (noindex, not in sitemap)`
3. سطر GATES (حوالي سطر 352)، السطر الحالي:
   `'<script>(function(){ if (window.MIGPLAN && !MIGPLAN.can("%s")%s) { try { sessionStorage.setItem("mig-gate", "%s"); } catch (e) {} location.replace("register.html#partner"); } })();</script>' % (feat, skip, ttl)`
   يبقى:
   `'<script>(function(){ var P = window.MIGPLAN; if (P && (P.gate ? P.gate("%s") : !P.can("%s"))%s) { try { sessionStorage.setItem("mig-gate", "%s"); } catch (e) {} location.replace(P.gateUrl ? P.gateUrl("%s") : "register.html#partner"); } })();</script>' % (feat, feat, skip, ttl, feat)`
4. `page(main=True)` لازم يرجّع نفس الـdoctype والـcharset والـviewport اللي في الصفحات التانية (`index.html`).
5. في الإنجليزي على 1366 الهيدر بيتجاوز 16 بكسل؛ الحل اختصار أو إخفاء نص زرار `.btn-intl`. ويُفضّل تغيير نص «دخول المصانع» الثابت لـ«دخول».
6. زي ما وكيل الفورمز قال: `mig-forms.js` و`holo.js` لصفحتي `advisor.html` و`meeting.html`.
